# Packs

Packs are the domain knowledge you name in a brief when the task needs it. A pack the brief does not name is not loaded, and the report says which packs it loaded. Each pack is a `PACK.md` with a `## How to verify` section.

- [python-untrusted-input](../packs/python-untrusted-input/PACK.md): loading YAML or JSON from untrusted sources, HTTP and GraphQL clients, opening files by path.
- [gha-security-dast](../packs/gha-security-dast/PACK.md): GitHub Actions workflow review (SHA pinning, permissions, expression injection), GYST callers and release rules (one pin, `CI green`, API limits) and OWASP ZAP automation.
- [threat-model](../packs/threat-model/PACK.md): assets, actors, trust boundaries and abuse cases, with risks ranked and each given a mitigation and a verification.
- [rf-emcomm](../packs/rf-emcomm/PACK.md): amateur radio and emergency-communications work; never key a transmitter, synthetic identifiers only.
- [linux-platform](../packs/linux-platform/PACK.md): service, udev, systemd, firewall, package and kernel change planning; privileged commands are handed to the human.
- [local-llm-routing](../packs/local-llm-routing/PACK.md): sending text work to a local Ollama server; code does counting, the model writes prose, and its output is verified against the source and reported on the `LOCAL-LLM:` line (measured on gemma4:12b only).
- [cyber-tier-review](../packs/cyber-tier-review/PACK.md): security and adversarial reviews on a vendor's high-trust cyber-access tier; use the tier model, fix the tier and rerun on a cutoff (never reword, never skip), the hardware-key error, single-flight runs, and a review that cannot show its answer is held, not clean. Tier and model values stay in your private config. CLI claims carry VERIFIED or INFERRED labels dated 2026-10-26.
- [opentofu-spacelift](../packs/opentofu-spacelift/PACK.md): OpenTofu run through Spacelift; plan before apply with blast radius and rollback, one explicit stanza per stack, the Spacelift MCP read-only (`mcp:read`) unless a named task grants write, state and drift handling. Built from the maintainer's measured lessons and vendor docs dated 2026-10-30; the pack benchmark (#73) is pending.
- [twingate-doppler](../packs/twingate-doppler/PACK.md): work that touches Twingate access or Doppler secrets; the secret value is never read, printed, logged or passed to an agent (names only), least privilege with one request for the whole job, CI on OIDC identities and not long-lived tokens, Twingate must be on and a missing link is reported before any workaround, what rotation breaks, and never searching the secret stores for a credential to reuse. Built from the maintainer's measured lessons and vendor docs dated 2026-10-30; the pack benchmark (#73) is pending.
- [aws](../packs/aws/PACK.md): AWS work, which is planned by the maintainer and not yet in use; no long-lived keys in text, least-privilege IAM, OIDC from GitHub Actions and Spacelift with narrow subject conditions, security groups and IMDSv2, S3 Block Public Access and bucket policies, KMS key policies, CloudTrail and Config, budgets that alert but do not cap, Organizations and SCPs, and how it pairs with OpenTofu, Spacelift, Doppler and Twingate. Every rule carries a source page fetched 2026-10-30 and a VERIFIED or INFERRED label; the pack benchmark (#73) is pending.
- [web-quality](../packs/web-quality/PACK.md): measured delivery checks for static sites and pages (Lighthouse mobile, contrast, CLS and LCP, page-weight budget, text measure, tap targets, alt text and image dimensions, reflow) and Hugo with Cloudflare Pages build checks; says when to call the installed accessibility, web-design, ui-ux, frontend-design, web-perf and impeccable skills and chooses no aesthetics.
- [asset-production](../packs/asset-production/PACK.md): checks for shipped assets; a provenance manifest, QR codes (error correction, quiet zone, decode round-trip, no shortener), SVG hygiene, the PNG, favicon and OG size table, EXIF and GPS stripping, a license allow list, and print art specs.
- [copy-review](../packs/copy-review/PACK.md): pilot pack, no item measured; review of scripts, posts and show notes for sourced claims, resolving URLs, disclosure checked against the live platform text, a secret scan, authorized scope, length limits, and an owner banned-phrase grep. Points to the private voice skill and restates none of it.
- [media-dispatch](../packs/media-dispatch/PACK.md): pilot pack, the entry point for a one-person media team ("Dispatch"); classifies a request, loads the specialist packs, and answers with one decision and an ordered action list with estimated hours and what each action displaces, checked by code against a stated weekly capacity ceiling. It never overrides a `safe-live` BLOCK.
- [safe-live](../packs/safe-live/PACK.md): leak prevention for live and recorded security content; window-only or dedicated capture, a stream delay sized to the measured takedown time, notification shutdown, a redaction scene, a dated pre-live checklist, frame-sampled scrub of VODs, clips and thumbnails, a lab-only scope line, a disclosure kit always checked against the live platform or regulator text, and incident response (take down, rotate, notify). It can block any release and no other pack can override it.
- [clip-desk](../packs/clip-desk/PACK.md): about three finished vertical clips a week from recordings plus YouTube packaging; whole-recording search, standalone hook-context-payoff, 60 to 120 s (up to 180 s for technical stories), no stretching a weak clip, a dedupe ledger, caption and technical-name QA, a vertical framing check, and per-platform export presets probed with `ffprobe`.
- [stage-crew](../packs/stage-crew/PACK.md): live production and accessibility; one audio preset with alerts under voice, a six-scene set with hotkeys and a redaction scene, an alert diet, computed WCAG AA contrast, live captions as an owner decision, safe-area crops per destination, a vertical live layout and separate alert paths per platform.
- [front-door](../packs/front-door/PACK.md): schedule and distribution; one canonical schedule file, a link hub generated from one data file, matching Discord and Matrix rules, a platform priority list (a few by hand, the rest automated) and a weekly plan sized to a stated capacity ceiling. Its partner parity rule says that when a creator is partnered with two or more platforms, none is diminished against another in any surface.

The five media packs (`media-dispatch` first) are generic and public, with placeholders only; see [the media facts file](overlay-and-ownership.md#media-team-facts-file) for the private facts they expect.

On Claude Code a pack installs as a skill named `pack-<name>`. Copilot has no pack loader, so paste the pack into the brief or use the exporter on the [Install](install.md) page. Packs are named in the brief; see [Writing a brief](writing-a-brief.md).
